# Cybersecurity Incident Analysis

[← Back to index](../README.md)

Assignment topic: analyzing a security incident using the CIA Triad.

## Analysis framework
1. **What happened?** Timeline of events.
2. **What was affected?** Systems, data, users.
3. **CIA impact:** Confidentiality, Integrity, Availability.
4. **Root cause:** Technical or human weakness (misconfiguration, weak password, unpatched software, phishing).
5. **Impact:** Financial, reputational, legal.
6. **Prevention and lessons learned.**

## Incident response lifecycle
Preparation → Detection and Analysis → Containment → Eradication → Recovery → Post-incident review.
